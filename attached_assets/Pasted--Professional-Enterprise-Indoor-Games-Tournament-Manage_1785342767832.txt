# Professional Enterprise Indoor Games Tournament Management System



## Objective



Build a **professional, premium-quality, enterprise-grade web application** for managing an internal company Indoor Games Tournament.



This application is intended for company employees and tournament organizers. The UI should feel like a modern corporate application similar to **Microsoft 365 Admin Center, Atlassian Jira, Linear, Notion, or Monday.com**.



The application should **not** look like a student project or a basic CRUD application. Focus on a polished, elegant, responsive, and production-ready design with excellent user experience.



**This is a frontend-only project using mock data. Design the application so it can later integrate with a Spring Boot REST API and PostgreSQL database.**
